## User Stories
### Authentication
- As a user, I want to register and log in, so that my data is private to me.
- As a user, I want to stay logged in with a token, so I don't have to sign in repeatedly.

### Dashboard
- As a user, I want a dashboard showing the summary of projects, courses, today's tasks, and streak, so I can see everything in one page.

### Timetable
- As a user, I want to upload an image of my timetable.

### Courses
- As a user, I want to create, edit, and delete my own courses.

### Projects
- As a user, I want to create, edit, and delete my own projects.
- As a user, I want to share a project with someone by username, so we can collaborate.
- As a collaborator, I want to manage ONLY the tasks on a shared project

### Tasks
- As a user, I want to add tasks with a title, deadline, priority, and status to a project or course.
- As a user, I want to update a task's status, so I can track my progress.

### Pomodoro Sessions
- As a user, I want to start a Pomodoro timer and have the session logged automatically.
- As a user, I want to optionally note what I covered and link the session to a task.
- As a user, I want to see my current streak, so I stay motivated.
